Uso sin conexión

Cómo usarlo
  1. Con internet, pulsa el botón. Verás cuántos tests se guardan en este dispositivo.
  2. iPhone: abre la web desde el icono de la pantalla de inicio. Si aún no lo tienes, en Safari pulsa Compartir y «Añadir a pantalla de inicio».
  3. Tablet o portátil con Chrome: menú y «Instalar aplicación» (o «Añadir a pantalla de inicio»).
  4. Para comprobarlo, activa el modo avión y abre la web: el inicio y los tests deben cargar.

Hay que hacerlo una vez en cada dispositivo. Si pasas muchos días sin abrir la web, el móvil puede borrar lo guardado y bastará con volver a pulsar el botón. Cuando hay conexión, la web se actualiza sola.

Sincronización

Token de GitHub
Cómo configurarla

Tu progreso, errores, dudas y notas se guardan en este navegador. Para verlos igual en el PC, el móvil y la tablet, se sincronizan a través de un repositorio privado de GitHub que solo tú ves.

  1. En GitHub crea un repositorio nuevo llamado mondongon-datos, marcado como Private.
  2. Edita tu token (Settings, Developer settings, Personal access tokens, Fine-grained tokens) y añade ese repositorio con Contents: Read and write. Si no te deja editarlo, crea otro token que incluya los dos repositorios.
  3. En cada dispositivo, guarda el token en «Token de GitHub».
