Publicación directa

Se configura una sola vez. Hace falta un token de GitHub limitado a este repositorio; se guarda únicamente en este navegador.

Cómo crear el token (2 minutos)
  1. Abre github.com/settings/personal-access-tokens/new.
  2. Token name: mondongon. Expiration: 1 año.
  3. Repository access → Only select repositories → elige web-mondongon.
  4. Permissions → Repository permissions → Contents → Read and write (nada más).
  5. Generate token, copia el que empieza por github_pat_… y pégalo aquí abajo.

No compartas este token con nadie (tampoco con ChatGPT). Si lo pierdes o quieres cortar el acceso, bórralo en esa misma página de GitHub.
