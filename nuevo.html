Añadir test

Del PDF a la web en 3 pasos

Pide el test a tu IA en formato JSON, valídalo aquí y súbelo a GitHub. No hay que tocar código.

1 · Pide el JSON a ChatGPT

Adjunta tu archivo de preguntas y pega este prompt (cambia los textos entre corchetes).

Convierte las preguntas del archivo adjunto en UN ÚNICO bloque JSON (sin texto antes ni después) con exactamente esta estructura:

{
  "titulo": "Constitución Española · Artículos 10–23",
  "tema": "Constitución",
  "fecha": "AAAA-MM-DD",
  "preguntas": [
    {
      "ref": "Artículo 14",
      "q": "Enunciado de la pregunta",
      "opciones": ["Opción A", "Opción B", "Opción C", "Opción D"],
      "correcta": 0,
      "explicacion": "1-2 frases que justifican la respuesta correcta."
    }
  ]
}

Reglas:
- "correcta" es el índice de la opción correcta empezando en 0 (0 = primera, 3 = cuarta).
- Las opciones NO llevan letras ni numeración ("A)", "1.").
- Mantén el texto de preguntas y opciones tal como está en el archivo; no inventes preguntas.
- "tema" debe ser una categoría corta y repetible (p. ej. "Constitución", "Ley 39/2015", "Ofimática").
- "ref" es el artículo o apartado de referencia.
- "fecha" es la fecha en que hice el test, formato AAAA-MM-DD.
- Responde solo con el JSON válido.

2 · Pega el JSON y valídalo

3 · Descarga y sube a GitHub

  1. Entra en el repositorio de GitHub, abre la carpeta tests.
  2. Add file → Upload files, arrastra el archivo descargado y pulsa Commit changes.
  3. En 1–2 minutos aparece en la portada. Si no, recarga con Ctrl+F5.
