2. Revisa y publica

«Publicar» lo sube a tu repositorio y en 1 o 2 minutos aparece en la portada. «Solo descargar» es el método manual: después hay que subir el archivo a la carpeta tests de GitHub.

Publicación directa

Se configura una vez en cada navegador o dispositivo, también en el iPhone y en el acceso directo de la pantalla de inicio. Necesita un token de GitHub limitado a este repositorio, que se guarda solo en ese navegador.

Cómo crear el token (2 minutos)
  1. Abre github.com/settings/personal-access-tokens/new.
  2. Token name: mondongon. Expiration: Custom, a un año vista.
  3. Repository access: Only select repositories, y elige web-mondongon.
  4. Permissions, Repository permissions, Contents: Read and write. Nada más.
  5. Generate token. Copia el que empieza por github_pat_ y pégalo abajo.

No lo compartas con nadie, tampoco con ChatGPT. Guárdalo en un gestor de contraseñas o en una nota protegida, porque GitHub solo lo muestra una vez. Si lo pierdes o quieres cortar el acceso, bórralo en la misma página de GitHub.
